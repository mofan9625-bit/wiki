## 内容方法与价值原则

- **独立第三方视角：** 不以出价高低决定内容排序，商业合作与编辑判断分离。
- **决策优先：** 先明确预算、设备、用途和容错需求，再筛选协议、线路与套餐。
- **证据分层：** 区分服务商声明、公开资料、可重复测试与编辑判断，避免把宣传口径当作事实。
- **风险透明：** 明示价格时效、退款限制、长期预付风险及无法独立验证的部分。
- **持续维护：** 静态知识库会随客户端、协议生态、服务状态与常见故障变化而更新。
